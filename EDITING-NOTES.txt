QUICK EDITING NOTES — SAMPLE-DATA.JS VERSION

MAIN STORAGE
- Permanent meeting records are stored in sample-data.js.
- Firebase is no longer the source for meeting records.
- The website reads MEETING_RECORDS and sorts by date, newest first.

ADD A NEW MEETING
1. Open sample-data.js in GitHub.
2. Copy one complete meeting object inside MEETING_RECORDS.
3. Paste it at the top of the list.
4. Give it a unique id, for example: 2026-08-12-it-meeting.
5. Update the meeting details and tasks.
6. Commit the change.
7. Reload the GitHub Pages website.

IMAGES
- Add permanent evidence through the images array inside a task.
- Each image needs a URL; caption is optional.

IMPORTANT
- Keep commas between meeting and task objects.
- Keep quotation marks around text.
- Use YYYY-MM-DD for the meeting date.
- Import JSON only loads temporary browser data.
- Download Data JSON can be used as backup.
