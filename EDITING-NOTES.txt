QUICK EDITING NOTES — FIREBASE VERSION

1. Main storage:
   - Meeting records are saved to Firebase Realtime Database.
   - Records are stored under meetingRecords.
   - The latest record ID is stored under metadata/latestId.

2. To save a new meeting:
   - Fill in the form.
   - Click Generate.
   - Click Save to Firebase.

3. To view previous meetings:
   - Click Refresh List.
   - Choose a record from Previous meeting records.
   - Click Load Selected.

4. To change Firebase project settings:
   - Open firebase-config.js.
   - Replace the firebaseConfig values.
   - Make sure databaseURL is included.

5. Recommended database rules:
{
  "rules": {
    ".read": "auth != null",
    ".write": "auth != null"
  }
}

6. If using authentication:
   - Enable Email/Password in Firebase Authentication.
   - Add a user under Authentication > Users.
   - Add your GitHub Pages domain under Authentication > Settings > Authorized domains.

7. Backup:
   - Download Data JSON still works if you want a local backup copy.
